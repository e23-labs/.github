## 🏗️ Core Builds

### 🏦 [GRND](https://github.com/e23-labs/grnd) - Tokenisation & Issuance Infrastructure
> A modular platform for compliant, asset-backed issuance across private and public markets

**Key Features:**
- Asset structuring and tokenisation
- Custody integration
- Distribution management
- Lifecycle controls

**Status:** `POC & Regulatory Submission`

**Tech Stack:** TypeScript, NestJS, PostgreSQL, Blockchain Integration

---

### 💎 [STBC](https://stbc.xyz) - PQC-Secured Institutional Stablecoin Settlement Rails
> Sovereign-grade stablecoin infrastructure with Post-Quantum Cryptography

**Key Features:**
- Reserve-backed minting
- Compliant settlement
- Post-Quantum Cryptography (PQC)
- Long-term security

**Status:** `POC & Documentation`

**Tech Stack:** Blockchain, PQC, Security Infrastructure

**Repositories:**
- [`stbc-core`](https://github.com/e23-labs/stbc-core) - Core stablecoin protocol
- [`stbc-middleware`](https://github.com/e23-labs/grnd-stable-coin-middleware) - Security middleware with PQC

---

### 🤖 [AIxVC](https://aixvc.io) - Agentic Intelligence for Unified Financial Terminal
> Multi-agent intelligence layer aggregating signals and executing strategies

**Key Features:**
- TradFi and DeFi signal aggregation
- Autonomous strategy execution
- Risk boundary management
- Real-time market intelligence

**Status:** `Development & GTM`

**Tech Stack:** Python, AI/ML, LangChain, Real-time Data Processing

---

### 🎫 [Livepass](https://livepass.asia) - Blockchain-Enabled Event Launchpad
> Programmable ticketing and event management on blockchain

**Key Features:**
- Event launch and management
- Transparent ticket issuance
- Programmable settlement
- Consumer-scale operations

**Status:** `Live Operations` ✅

**Purpose:** Production proving ground for e23's tokenisation and settlement research

## 🎓 For Developers

### Getting Started

1. **Explore our projects**
   ```bash
   # Clone a repository
   git clone https://github.com/e23-labs/[repository-name]
   
   # Install dependencies
   npm install
   
   # Run tests
   npm test
   
   # Start development server
   npm run dev
   ```

2. **Read the documentation**
   - Each repository contains detailed `README.md`
   - API documentation available in `/docs` folders
   - Architecture decisions documented in `/docs/architecture`
